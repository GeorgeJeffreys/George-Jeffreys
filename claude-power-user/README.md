# Claude Power-User Kit

Start with **[PLAN.md](PLAN.md)**. It covers the pillars, the daily rhythm and the 30-day rollout.

This folder is a starter kit. Copy it into its own private repo (`claude-os`), which doubles as your Obsidian vault:

| Folder | Copy to | What it is |
|---|---|---|
| `vault-template/CLAUDE.md` | `claude-os/CLAUDE.md` | Router file that tells Claude where everything lives |
| `vault-template/user-CLAUDE.md` | `~/.claude/CLAUDE.md` | Your global instructions for every session |
| `context/` | `claude-os/00-context/` | Interview outlines. Claude fills them in with you |
| `skills/` | `claude-os/.claude/skills/` (+ upload to claude.ai) | Repeatable playbooks |
| `agents/` | `claude-os/.claude/agents/` | Subagent specialists |
| `routines/` | Paste into `/schedule` or Cowork scheduled tasks | Prompts for the recurring jobs |
