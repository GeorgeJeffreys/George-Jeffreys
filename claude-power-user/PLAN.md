# The Claude Power-User Plan

**Goal:** you get the most out of Claude while doing as little hands-on work as possible.
**Principle:** *Context in → routines run → you review, approve, and correct.* Every correction you make gets written back into context. Over time Claude needs less steering.

Status as of 23 Sep 2026. Features marked **(beta)** or **(verify)** are still changing, so check the linked docs before relying on them.

---

## The architecture in one picture

```
            ┌──────────────────────────── YOU (phone / laptop) ─────────────────────────────┐
            │  review briefs · approve drafts · answer questions · dictate thoughts          │
            └───────────────▲───────────────────────────────────────────┬───────────────────┘
                            │ push / email                               │ Dispatch / chat
   ┌────────────────────────┴───────────────────────────────────────────▼───────────────────┐
   │ PILLAR 4  RHYTHM: Routines (cloud, scheduled) · Cowork scheduled tasks · Projects        │
   │ PILLAR 5  TEAM:   subagents (chief-of-staff, researcher, drafter) · agent teams          │
   │ PILLAR 3  SKILLS: write-like-me · morning-brief · inbox-triage · meeting-to-vault · …     │
   ├──────────────────────────────────────────────────────────────────────────────────────────┤
   │ PILLAR 2  CONNECTORS (MCP): Gmail · Calendar · Drive · Granola · Obsidian · Todoist · …   │
   │ PILLAR 1  CONTEXT: "Claude OS" repo/vault: about-me, how-I-think, people, projects, notes │
   └──────────────────────────────────────────────────────────────────────────────────────────┘
```

**Pillar 1 matters most.** Everything above it gets better as your context gets better.

## PILLAR 0: Plan & surfaces (day 1, ~30 min)

| Do | Why |
|---|---|
| Upgrade to **Max** (5x to start, 20x if routines hit limits) | Routines, Projects, Cowork, Dispatch and Chrome all draw on one usage pool, and heavy automation uses up Pro's allowance quickly |
| Install **Claude Desktop** (Cowork + Code tab) and the **mobile app** | Cowork runs local files, Office docs and scheduled tasks. Mobile lets you Dispatch tasks and approve from your phone |
| Install **Claude in Chrome** | Covers any web tool that has no connector (bank portals, booking sites, internal admin UIs) |
| If you use Office, add **Claude for Excel / PowerPoint / Word / Outlook** | Your DG and Alsama deck skills already exist in your account, and they're more useful inside PowerPoint |
| **Projects in claude.ai/code (beta):** check the sidebar for a *Projects* tab | Per the docs it's rolling out gradually to Pro/Max cloud-session users. Moving to Max and using cloud sessions regularly makes you an existing user it rolls out to. Docs: https://code.claude.com/docs/en/claude-projects |

Until Projects arrives, you can get most of the same result with (a) one **Claude OS repo** (below) that every cloud session starts from, (b) tagged cloud sessions, and (c) Routines.

## PILLAR 1: Context (your "Claude OS")

Keep **one private GitHub repo, which is also your Obsidian vault.** It's version-controlled, so every edit Claude makes can be undone. Claude Code opens it directly, cloud sessions and Routines clone it, and Obsidian reads it on your laptop and phone.

```
claude-os/                      ← git repo + Obsidian vault
├── CLAUDE.md                   ← router: tells Claude what lives where (template in vault-template/)
├── 00-context/                 ← small, indexed files. Claude reads the index, then only what it needs
│   ├── about-me.md             ← role, orgs, goals, constraints, preferences
│   ├── how-i-think.md          ← problem-solving style, decision rules, taste
│   ├── principles.md           ← non-negotiables, values, "never do X"
│   ├── people.md               ← VIPs, relationships, how to treat each
│   ├── voice.md                ← generated by the write-like-me skill
│   └── current-priorities.md   ← refreshed weekly by the weekly-review routine
├── 01-projects/  02-areas/  03-resources/  04-archive/   (PARA)
├── daily/YYYY-MM-DD.md         ← written by the morning brief + evening wrap
├── meetings/YYYY-MM-DD-title.md← written by meeting-to-vault (from Granola)
├── inbox/                      ← anything you dump: voice memos, links, half-thoughts
└── .claude/  skills/ agents/ settings.json   ← your harness, versioned with your brain
```

**Set it up (≈2 h, mostly Claude talking to you):**
1. Create the private repo `claude-os` and copy in `vault-template/`, `context/`, `skills/` and `agents/` from this folder.
2. Open it in Obsidian (File → Open folder as vault). Install the **Obsidian Git** plugin so it syncs automatically.
3. **Run the interview.** Start a Claude session in the repo and say: *"Interview me using `00-context/*.md` as the outline. Ask one question at a time, 20 minutes, then write the files."* Use voice dictation. Talking is 3–4x faster than typing, and you sound more like yourself.
4. Set `~/.claude/CLAUDE.md` (user-level, applies to every project) to import the core files: `@~/claude-os/00-context/about-me.md`, `@…/how-i-think.md`. Import only the small, stable files. Everything else stays behind the index, loaded when needed.
5. For **claude.ai chat**, turn on Memory and paste a condensed about-me into Settings → Profile. If you've used ChatGPT, run the *import-memory* skill on your export.

**Rule:** after you correct Claude, say *"remember this"*. It then updates the right context file (or auto-memory) so it doesn't repeat the mistake.

## PILLAR 2: Connectors (MCP to every tool)

Add each connector once at **claude.ai → Settings → Connectors**. It then shows up in chat, Cowork, cloud Claude Code and Routines. Use `claude mcp add --scope user` only for local-only servers.

| Tier | Tool | How | Notes |
|---|---|---|---|
| **Core (day 1)** | Gmail, Google Calendar, Google Drive | Anthropic-built connectors | Gmail and Drive are already connected to this session |
| | **Granola** | Directory connector, or `claude mcp add --transport http granola https://mcp.granola.ai/mcp` | Official, OAuth. Free tier sees only the last 30 days, and paid plans unlock full transcripts **(verify)** |
| | **Obsidian** | Local REST API plugin (coddingtonbear), which has a built-in MCP at `https://127.0.0.1:27124/mcp/` | Works only on your laptop. Cloud routines reach the vault through the **git repo** |
| | GitHub | Directory connector | So cloud sessions and Routines can read and write `claude-os` |
| **Work** | Slack, Notion, Linear/Asana, Microsoft 365, Canva | Directory | Connect whatever you actually use |
| **Life admin** | Todoist (`https://ai.todoist.net/mcp`), Readwise (`https://mcp2.readwise.io/mcp`) | Official remote MCPs | Tasks and reading highlights |
| | **Zapier MCP** | Directory | Covers any of ~9,000 apps with no connector. Allow only specific actions |
| **Later, read-only, with care** | Apple Reminders/Notes, WhatsApp, Monarch/Copilot Money | Community MCPs (macOS) | Unofficial. These carry prompt-injection and data-leak risk. Never give them write or send access |

**Safety defaults:** Claude drafts and never sends. It proposes calendar changes and never accepts them for you. Finance access is read-only. Add auto-send only for narrow cases once a skill has earned your trust.

### Meetings → Obsidian pipeline
1. **Granola** records and transcribes. Claude doesn't capture meetings itself.
2. For raw sync, install the community **"Granola API Sync"** Obsidian plugin, or Granola-to-Obsidian by dannymcc. Either writes into `meetings/`.
3. For intelligence, the **meeting-to-vault** skill (in this folder) pulls from the Granola MCP and writes a structured note: decisions, actions with owners, and people updates. It adds actions to Todoist and links everything from the day's `daily/` note.
4. Run step 3 as a routine at 18:00 so it covers every meeting that day.

## PILLAR 3: Skills (your repeatable playbooks)

A skill is a folder with a `SKILL.md`. Claude loads it automatically when the task matches, or you call it with `/name`. Keep them in `claude-os/.claude/skills/` (versioned) and **upload the important ones to claude.ai** (Settings → Capabilities → Skills) so chat, Cowork and mobile can use them too.

Starter set in `skills/`:

| Skill | Does | Build effort |
|---|---|---|
| `write-like-me` | Drafts email/Slack/docs in your voice. Built from ~200 of your sent emails, split by audience | 30 min (Claude does the analysis) |
| `morning-brief` | Calendar + urgent email + open actions + meeting prep → `daily/` note + push notification | 10 min |
| `inbox-triage` | Labels, drafts replies (via write-like-me), and surfaces only what needs you | 10 min |
| `meeting-to-vault` | Granola → structured meeting note → Todoist actions → people updates | 10 min |
| `weekly-review` | Reviews the week, refreshes `current-priorities.md`, flags dropped balls | 10 min |

**Also, already in your account:** `designers-guild-slides`, `alsama-deck`, `morning`, `skill-creator`, docx/xlsx/pptx/pdf.
**Then:** whenever you catch yourself explaining the same thing twice, say *"turn this into a skill"*. `skill-creator` writes it and tests it with evals. Aim for one new skill a week.

## PILLAR 4: Rhythm (routines that run without you)

**Routines** (claude.ai/code, `/schedule`) run in the cloud with your connectors, even while your laptop is off, and notify your phone when they finish. **Cowork scheduled tasks** do the same but run on your machine, so they can reach local files, the Obsidian MCP and Office. Prompts are in `routines/`.

| When (local) | Routine | Runs in | Output |
|---|---|---|---|
| Weekdays 06:30 | **Morning brief** | Cloud Routine | `daily/` note + push: "3 things that matter today, 2 decisions needed, meeting prep" |
| Weekdays 07:00, 12:30, 16:30 | **Inbox triage** | Cloud Routine | Labels applied, drafts waiting in Gmail, a short "needs you" list |
| Weekdays 18:00 | **Meeting wrap** | Cowork (needs vault) or Cloud (via git) | Meeting notes, actions in Todoist, people.md updates |
| Fri 16:00 | **Weekly review** | Cloud Routine | Week summary, updated priorities, list of dropped balls |
| Sun 19:00 | **Week ahead** | Cloud Routine | Calendar sanity check, prep list, time-blocking proposal |
| 1st of month | **Life admin sweep** | Cowork + Chrome | Subscriptions, bills, renewals, a documents-to-file list |

Run each routine **manually for a week and correct it** before you schedule it. Proposing and correcting first, then automating, is the order that builds trust.

## PILLAR 5: Team (subagents & agent teams)

- **Subagents** (`agents/*.md`) are specialists with their own context window, tool limits and model. They keep your main thread clean.
  - `chief-of-staff` orchestrates: reads context, delegates, and presents decisions.
  - `researcher` does web + Drive + Gmail digging and returns a sourced summary.
  - `drafter` always uses write-like-me and never sends.
  - `analyst` handles spreadsheets and numbers, with its reasoning shown.
- **Agent teams (experimental)** are multiple full Claude sessions sharing a task list and messaging each other. Turn them on with `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`. Use them for large one-off efforts like "research 5 suppliers in parallel and debate a recommendation", not daily work.
- **Cloud fan-out:** from any cloud session you can ask Claude to *"spin up 3 sessions for X, Y, Z"*. It creates sibling sessions and reports back. Projects formalises this once you have it.

---

## PILLAR 6: Feedback loop (how the system gets smarter)

1. **Correct in the moment:** say *"remember this"*, and the context file or skill gets updated.
2. **Friday review:** the weekly-review routine lists that week's corrections and proposes edits to skills and context. You approve with a single "yes".
3. **Monthly, 30 min:** prune `CLAUDE.md` (keep it under ~200 lines, with everything else behind the index), retire unused skills, and add one new connector or skill.

## What a normal day looks like (≈20–30 min of hands-on time)

| Time | You | Claude (already done) |
|---|---|---|
| 07:00 (5 min, phone) | Read the brief. Tap to approve or edit 3–5 drafted replies | Brief written, inbox triaged, drafts waiting, meeting prep in the daily note |
| During the day | Take meetings with Granola running. Dump thoughts to Claude mobile by voice (*"add to inbox: …"*) | Midday triage. Dispatch tasks you sent from your phone run in Cowork |
| Ad hoc | *"Draft the DG board paper from last week's notes"* → review | Pulls meetings, Drive and context. Uses the deck skill and your voice |
| 18:00 (5 min) | Skim the meeting wrap. Tick or kill actions | Meeting notes filed, actions in Todoist, people updated |
| Friday (15 min) | Read the weekly review. Approve priority and skill updates | Week summarised, corrections folded back into the system |

## 30-day rollout

| Week | Outcome | Key actions |
|---|---|---|
| **1: Foundation** | Claude knows who you are | Max plan · Desktop/mobile/Chrome · create `claude-os` repo + vault · interview → context files · `~/.claude/CLAUDE.md` · connect Gmail/Cal/Drive/GitHub |
| **2: Voice & capture** | Claude writes like you, and meetings land in the vault | Run `write-like-me` build · Granola + connector + Obsidian sync · Obsidian MCP · Todoist · upload skills to claude.ai |
| **3: Automate** | Mornings and inbox run themselves | Run the brief and triage manually for 5 days, correcting as you go → schedule as Routines · add meeting-wrap |
| **4: Scale** | You delegate projects, not just tasks | Subagents · weekly review · first agent-team run on a real project · Projects when it reaches you · monthly prune |
