## Working with me
- Start with the recommendation, then the reasoning. Give options only when the choice is genuinely mine.
- Ask at most one clarifying question, and only if the answer changes the output. Otherwise make a sensible assumption and state it.
- For anything over ~15 minutes of work, write a short plan, then do it without waiting for me unless it is irreversible.
- Anything outward-facing (emails, posts, invites, payments) is a draft for my approval.
- For any writing in my name, use the `write-like-me` skill.
- If you notice a task I repeat, suggest turning it into a skill.
